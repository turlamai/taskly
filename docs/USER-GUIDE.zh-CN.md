# Taskly 使用指南

[English](USER-GUIDE.md) · **简体中文**

用清单、快速录入和定时提醒管理本地待办。

## 当前可用状态

开发预览，尚未开放付费购买。未来官方桌面版开售时再公布实际交付条款。

## 平台与安装

提供 macOS、Windows、Linux 桌面预览版。按发布附件标注选择系统与 CPU；移动端和手表端尚未交付。

从[官方 Releases](https://github.com/turlamai/taskly/releases)选择明确标注系统和架构的附件，阅读该版本说明并核对附带校验文件。未列出的附件或平台不视为已交付。预览构建可能没有系统发行者签名或公证；不要为安装而关闭系统安全保护。

- Windows：x64 MSI 会接入开始菜单和“应用和功能”，ZIP 是便携版。当前预览 MSI 尚无 Authenticode 签名，发行者信任与 SmartScreen 信誉还未达到生产发布标准。
- macOS：打开 DMG，把 Taskly 拖入“应用程序”。当前预览版是临时签名，尚非 Developer ID 签名与公证；若 Gatekeeper 拒绝，不要因此关闭 Gatekeeper。
- Linux：Debian/Ubuntu 使用 deb，Fedora 兼容系统使用 rpm，也可便携运行 AppImage，或使用 Flatpak 包（`flatpak --user install ./taskly-<版本>-linux-<架构>.flatpak`；包内只含应用本体，首次安装时会从 Flatpak 远端拉取 GNOME Platform 运行时）。系统包会安装桌面入口和图标；升级与卸载应使用同一个包管理器（或 `flatpak --user update`）。

## 第一次使用

1. 首次启动显示数据库引导页。选择“创建数据库”，挑选文件夹并输入名称（应用在该文件夹创建 `taskly.sqlite`；同名文件已存在时不会写入任何内容），或选择“打开已有数据库”。新数据库打开后自带默认清单——在空状态提示上方添加一条不含敏感信息的任务即可；不需要账号、云绑定或额外设置。若上次打开的数据库找不到，引导页提供“重新定位”和“重试”，绝不会自行新建替代数据库。
2. 打开任务并选择日期，再点击明确可见的“保存”。退出并重新打开 Taskly，确认任务和日期都已持久化。
3. 提醒：提醒字段会持久化，但 OS 通知投递仍在 staged（#131）——任何状态下都暂不要期待横幅。

## 数据、备份与恢复

任务存放在一个 SQLite 文件里，位置是你创建或打开数据库时选定的；设置 → 数据 会显示当前名称与位置，并提供“所在文件夹”操作。配置在 ~/.taskly/config.ini。退出全部 Taskly 进程后备份该数据库所在文件夹，包含可能存在的 WAL/SHM 文件；先在副本中验证恢复。把正在使用的数据库放进云同步目录，不等于支持多端并发编辑。（源码 CLI 在尚未记录数据库时回退到 ~/.taskly/tasks.db。）

## 键盘与编辑

Ctrl/⌘+K 聚焦搜索。在任务列表里 Enter（或编辑操作）打开行内编辑；编辑区始终显示“保存”和“取消”。Enter 保存，Escape 或“取消”丢弃整份草稿，点击编辑区外部则提交草稿。日期 chip 循环 无 → 今天 → 明天；任意日期与时间在详情弹层的日期/时间字段里设置。编辑器里选择日期只修改草稿；“保存”、Enter 或点击另一行才会持久化，并显示保存中、成功或错误反馈。显式保存失败时草稿会保留以便重试。删除会暂存约六秒；撤销会恢复相同的任务 ID 与全部元数据。多选、批量操作、方向键行导航与 Ctrl/⌘+1…4 / N / F / ⇧C 快捷键是对标目标，本宿主尚未落地（见 UX-BENCHMARKS）。

任务行上的 ⓘ 按钮在三平台都会打开任务详情弹层：完成状态、标题、日期、时间、优先级、标签、子任务、备注、链接与所属清单集中在一层。所有更改即时保存——关闭不会丢弃——保存失败时错误会锚定到对应字段。点击任务标题仍会打开行内编辑。

## 联网、密钥与隐私

核心待办功能在本地运行。主动打开的链接会访问外部服务。应用自身目前不发起任何网络请求：应用内更新检查尚未接通（#157）。数据库和诊断文件可能包含任务标题与备注。

## 已知限制

提醒判定由公共核心在各平台一致执行，但 OS 通知投递仍在 staged（#131）：字段持久化、暂不触发。应用内更新检查与「关于」对话框尚未落地本宿主（#157）。桌面发行包尚未附带独立 CLI；源码 CLI 用法见 README。

## 更新与卸载

先备份数据，再阅读目标版本说明。本版本不会自行检查更新（#157）：请到 [Releases](https://github.com/turlamai/taskly/releases) 下载新包，对照该版本的 `SHA256SUMS` 校验后覆盖安装。deb/rpm 与 Flatpak 副本通过系统包管理器（或 `flatpak --user update`）升级，由其负责。不要安装无法校验的文件。更新失败时保留现有数据与错误信息，使用可信发行包恢复；卸载程序通常不等于删除独立的数据目录，删除个人数据前先确认备份。

DMG、MSI、deb/rpm 与便携压缩包只替换应用文件，不应修改 `~/.taskly/`。更新失败时退出全部 Taskly 进程，用相同安装形态重新安装上一版可信构建；便携版可直接回到上一版程序目录。各安装形态的完整回滚表见下方更新说明。

Windows MSI 从“应用和功能”卸载，macOS 从“应用程序”删除，Linux 则使用安装时的包管理器卸载；AppImage 与 ZIP 删除对应程序文件或目录即可。这些操作有意保留 `~/.taskly/`，也不会触碰你放在别处的数据库文件；个人数据只能在确认备份后另行明确删除。

## 获得帮助

在 [GitHub Issues](https://github.com/turlamai/taskly/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
