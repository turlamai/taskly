设计原则

设计，是为了退到幕后。

宁静的色彩、考究的排版，没有多余的东西。让你专注于执行，而非管理。

排程速记

给任务加个修饰符：「Standup @9am」「买牛奶 +1d」「发布 @5pm fri」。Taskly 提取时间，剩下就是任务。无需拨盘，无需翻日历。

查看完整语法 →

隐私优先

任务存储在本地 SQLite 数据库。无需账号，无云端，无追踪。

真正的跨平台

macOS、Windows、Linux 原生应用，到处都是同样清爽的界面。

备份与安全迁移

退出所有 Taskly 进程后备份整个数据目录。不要让多台设备同时编辑备份与迁移中的 SQLite 文件；WAL 不提供跨设备文件同步。

保留你的副本。

自动化

会输出 JSON 的命令行

Taskly 的每一项操作都有稳定的 JSON 命令行——脚本化、管道传递、交给 AI 代理。稳定的退出码、结构化输出，毫无意外。

# add a task, get JSON back
$ taskly add "Ship landing-page @friday 5pm" --list "Work" --json
$ taskly list --status incomplete --json | jq '.[] | .text'

桌面安装包目前不包含独立的 taskly CLI。以上示例需要从源码运行 CLI。

发布

三大桌面，一个核心。

Taskly 覆盖 macOS（SwiftUI）、Windows（WinUI 3）与 Linux（GTK4）——共享 Racket 核心驱动轻薄的第一方宿主，JSON CLI 由 63 例 golden 套件钉死，数据就是单个本地 SQLite 文件。桌面 GUI 可下载安装；CLI 目前需从源码运行。

三端原生 · 一个核心

macOS 用 SwiftUI，Windows 用 WinUI 3，Linux 用 GTK4——每个平台都是第一方手感，全部逻辑在一个 Racket CS 核心里经类型化 RPC 驱动它们。

应用内更新 · 三平台

启动时静默检查 + 设置里手动检查。后端验证 Ed25519 签名的更新清单并下载产物，宿主负责安装——绝不碰你的数据。

Agent CLI · Golden 钉死

无头 CLI，稳定的 JSON 输出与退出码：`taskly add "买牛奶" --due tomorrow --json`。跨平台字节级一致由 CI 中的 63 例 golden 套件钉死。

源码可得 · BUSL-1.1

桌面核心源码可得——自由检视、分叉与研究；每个版本四年或 2030-09-28 转为 MIT。数据格式与 CLI 都是成文的契约，而非偶然。

开始使用

从一次有效使用开始。

提供 macOS、Windows、Linux 桌面预览版。按发布附件标注选择系统与 CPU；移动端和手表端尚未交付。

01

创建清单，添加一条不含敏感信息的任务；保存前核对解析出的日期。

02

完成任务，重新打开应用，确认状态已保存。

03

使用提醒前允许系统通知，在应用运行时测试一次；不要假定退出应用或电脑休眠后仍能送达。

提醒选择逻辑仍需跨宿主收敛（#62）。桌面发行包尚未附带独立 CLI；源码 CLI 用法见 README。
