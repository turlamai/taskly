# Third-Party Notices

Taskly builds on third-party software. This file is the maintained
overview. The **authoritative, complete inventory for any given build**
is the `THIRD_PARTY_NOTICES.txt` generated by the pinned Rivet release
toolchain (`raco rivet release`) into each platform's release artifact,
together with the CycloneDX SBOM (`sbom.cdx.json`) produced alongside
it. This file does not duplicate the generated notices; it groups what
the build distributes so reviewers know what to expect there.

## Racket runtime and catalog packages

The distributed runtime embeds Racket CS (9.3) through Rivet's stable
C ABI. Taskly's declared package dependencies (`racket/info.rkt`) are
`base`, `crypto-lib`, `db-lib`, `net-lib` and `rivet`.

- The Racket runtime and its main-distribution packages in the
  embedded closure — including `base`, `db-lib`, `net-lib` and
  `cext-lib` — are dual-licensed Apache-2.0 OR MIT per their package
  metadata and the `LICENSE-MIT.txt` / `LICENSE-APACHE.txt` files
  shipped with the Racket distribution.
- `crypto-lib` (Ed25519 / SPKI key handling for the updater) is
  Apache-2.0 per its package metadata.
- `rackunit-lib` (Apache-2.0 OR MIT) is a build/test dependency only;
  it is not part of the shipped runtime.
- [Rivet](https://github.com/turlamai/rivet) — typed RPC, client
  codegen, embedded runtime and release machinery — is MIT.
  [Keel](https://github.com/turlamai/keel), part of Rivet's runtime
  dependency closure, is MIT.

## Linux bundles

The Linux host uses GTK 4 and GLib — system libraries on deb/rpm/
tarball installs, part of the bundled dependency closure inside the
AppImage. These GNOME libraries are licensed LGPL-2.1 and are used as
unmodified shared libraries. The exact bundled set for an AppImage
build is listed in that build's generated notices file.

## Platform frameworks

The hosts use OS-provided frameworks: SwiftUI, AppKit and CryptoKit on
macOS; WinUI 3 / Windows App SDK and C++/WinRT on Windows. These ship
with the operating system or its SDK; no separate notice inventory is
reproduced here.
